# Phase 2：模板市场（UGC）重启门禁指标

| 属性 | 内容 |
|------|------|
| 状态 | **草案 / 待数据验证** |
| 日期 | 2026-06-23 |
| 关联 ADR | [MVP 隐藏模板市场](./2026-06-23-mvp-hide-template-market.md) |

---

## 目的

在 MVP 关闭 C 端模板模块后，用**可量化门禁**决定是否重新开放独立「模板」导航与 UGC 市场，避免过早承担治理成本。

## 建议门禁（需同时满足或经产品负责人豁免）

| 指标 | 建议阈值 | 说明 |
|------|----------|------|
| 月活（MAU） | ≥ **3,000** | 有足够用户基数再开 UGC，否则供给与互动均不足 |
| 计划创建完成率 | ≥ **35%**（进入创建页 → 成功定稿） | 核心闭环稳定后再加第二频道 |
| 审核运营人力 | ≥ **0.5 FTE** 或外包 SLA | 能处理 pending_review、举报、下架（见 UGC PRD P0） |
| 官方预设内嵌套用率 | ≥ **8%**（创建页点击官方示例 / 进入创建页 UV） | 证明「模板式冷启动」有需求，再扩展为市场 |
| 内嵌预设 → 定稿转化 | 不低于「空白创建」转化率的 **90%** | 避免开放市场后体验倒退 |

## 重启动作清单

1. 构建/部署设置 `VITE_FEATURE_TEMPLATES=true`。
2. 恢复侧栏「模板」与 `/templates` 路由（取消重定向）。
3. 恢复计划详情「发布为模板」入口。
4. 确认管理端审核/举报流程已演练（至少一次 dry-run）。
5. 埋点对比：`template_detail_click`、`template_use`、`template_publish` 漏斗基线。

## 未达标时的策略

- 继续隐藏 UGC 市场；仅保留创建页内嵌官方预设。
- 每季度复评指标；不强制删除已冻结代码。
