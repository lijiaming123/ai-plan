# Feature：Analytics 预聚合（按日/维度）

| 属性 | 内容 |
|------|------|
| 状态 | **待审批**（2026-04-22） |
| 所属 Epic | `.ai/epics/epic-web-admin-growth-analytics.md` |
| 优先级 | P0 |
| 目标产出 | 为报表提供可快速查询的日级聚合数据 |

---

## 1. 目标

基于 raw 事件表与业务表（用户/计划/打卡），产出：

- `telemetry_daily_agg`：按日、事件、维度（渠道/版本/平台）的 users/events 计数
- 为漏斗/留存/路径提供可复用的查询基座，避免大范围扫 raw

---

## 2. 范围

### In Scope

- 聚合表 schema
- 聚合 job（可定时/按需触发），幂等
- 基础回填：最近 N 天（例如 30/90）的重算能力

### Out of Scope

- 分布式任务队列（P2）
- 引入列存/数仓（P3）

---

## 3. 验收标准

1. 给定某日 raw 事件数据，聚合表能产出正确 users/events（抽样对账）。
2. 同一日重复执行聚合 job，结果一致（幂等）。
3. 聚合任务失败不会影响 API 主流程，并有错误日志/指标。

---

## 4. 关联 Stories（建议）

- S1：设计并落库聚合表 schema（含索引）
- S2：实现按日聚合 job（含重算参数）
- S3：为 analytics 查询提供聚合读取接口（service）
