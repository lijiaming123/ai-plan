# Feature：举报与处置闭环（report → triage → moderate）

| 属性 | 内容 |
|------|------|
| 状态 | **待审批**（2026-05-09） |
| 所属 Epic | `.ai/epics/epic-web-user-template-market-ugc.md` |
| 优先级 | P0 |
| 目标产出 | 用户可举报，管理员可处置并可追溯 |

---

## 1. 目标

- 用户端举报入口：原因码 + 描述 + 证据（可选）\n
- 举报记录表与管理端列表\n
- 处置动作联动模板状态机（下架/封禁）\n
- 举报与处置全过程可追溯（审计 + 状态流转）\n

---

## 2. 验收标准

1. 用户可举报已发布模板，举报成功返回 201。\n
2. 管理员可查看举报列表并对模板执行处置。\n
3. 处置后模板对外不可见且不可套用。\n
4. 举报与处置动作在审计日志可查询。\n
