## 1. 当前已具备（摘录现状）

> 代码现状（供对照）：\n

- **市场浏览**：系统预设 + 用户模板列表；筛选（q/category/tag）；排序（new/likes）；分页。

## 2. P0 缺口（不补齐很难商用/易被滥用）

### 2.1 治理闭环缺失（审核/下架/封禁）

- **现状**：`publishMarketTemplate` 直接写入 `status: published`（上线即公开）。\n
- **缺口**：\n
  - 模板状态机：`pending_review/published/rejected/unpublished/banned` 等\n
  - 审核队列与审核记录（原因码、备注、批量处理）\n
  - 下架与封禁动作（模板/作者层级）\n
  - 处置对外可见性：公开市场只展示 `published`\n

**风险**：违规内容/低质内容/广告引流快速传播，导致平台合规与品牌风险。\n
**缓解**：默认审核；高风险触发强制审核；处置可追溯（审计）。\n

### 2.2 作者侧生命周期管理不足

- **现状**：只有“发布”；缺少编辑/撤回/下架/删除/重发/版本。\n
- **缺口**：\n
  - 作者可见的状态与审核反馈\n
  - 编辑元信息触发重新审核\n
  - 作者主动下架（unpublish）与重新提交（re-submit）\n

**风险**：作者无法修正错误或应对举报；运营/审核只能硬下架，体验与治理成本高。\n
**缓解**：作者工具链（编辑/下架/重提）+ 明确规则。\n

### 2.3 反滥用/风控缺失（频控、刷赞刷套用）

- **现状**：点赞/收藏存在幂等，但无频控；发布/举报/套用无基础限流。\n
- **缺口**：\n
  - 发布/点赞/收藏/套用/举报的限流（userId + IP + 时间窗）\n
  - 异常检测的最小指标（短时爆发、同IP多账号）\n
  - 封禁/限制发布能力（与治理闭环联动）\n

**风险**：刷赞提升排序、刷套用造假热度、滥发模板导致审核队列爆炸。\n
**缓解**：基础频控 + 阈值告警；后续接入更强风控。\n

### 2.4 审计与可追溯不足

- **现状**：模板域尚未形成统一审计口径（尤其管理员审核/处置）。\n
- **缺口**：\n
  - 关键动作审计：publish/edit/review/unpublish/ban/apply/report\n
  - 审计查询（管理端）与留存策略\n

**风险**：无法追责/对外解释；合规审查困难。\n
**缓解**：复用现有 audit 基础设施，模板域全量接入。\n

### 2.5 合规要素缺失（举报、内容规范、隐私）

- **现状**：无举报入口/处理流程；未明确“不得包含个人隐私/敏感信息”。\n
- **缺口**：\n
  - 举报入口与举报原因码\n
  - 处理流程与处置动作\n
  - 发布规范与前端勾选确认；对 payload 做脱敏/裁剪策略\n

## 3. P1 缺口（提升转化与运营效率）

### 3.1 模板详情页与预览能力不足

- **现状**：`GET /templates/market/:id` 不返回 payload；前端无详情页。\n
- **缺口**：\n
  - 详情页（模板介绍、作者、统计、标签/分类）\n
  - 结构化预览：从 payload 生成“目标/期限/摘要/粒度”等可读信息\n
  - 风险提示：内容规范、可复制性说明\n

### 3.2 运营配置缺失（推荐位/精选/官方模板）

- **缺口**：\n
  - 官方模板与精选（置顶/推荐）\n
  - 分类/标签体系治理（黑名单词、同义词）\n
  - 冷启动策略（新模板曝光、质量筛选）\n

### 3.3 搜索与排序质量

- **现状**：DB contains + likes/new 排序。\n
- **缺口**：热度（like+apply+时间衰减）、反作弊加权、检索增强。\n

---

## 4. P2 缺口（规模化与体验打磨）

- 多语言与地区化（locale、敏感词/合规模板随地区变化）\n
- 多租户/组织隔离（若未来做企业内市场）\n
- 观测与增长：SLO/告警/漏斗看板、A/B、推荐质量评估\n

---

## 5. 风险总览（Top）

| 风险 | 级别 | 触发场景 | 缓解 |
|------|------|----------|------|
| 违规内容扩散 | 高 | 发布即上线 | 默认审核 + 举报处置 + 可追溯审计 |
| 刷赞/刷套用 | 高 | 排序依据 likes/new | 频控 + 异常阈值告警 + 反作弊排序 |
| 审核队列爆炸 | 中 | 滥发模板 | 发布频控 + 限制发布/封禁 |
| payload 泄露隐私 | 中 | 模板导出内容包含个人信息 | payload 白名单校验 + 详情页裁剪 + 发布规范 |
| 无法复现/纠纷 | 中 | 模板更新覆盖导致历史不一致 | 版本快照 + apply 绑定版本 |
