# Story 001：Telemetry 事件字典 v1（命名/属性/脱敏规则）

| 属性 | 内容 |
|------|------|
| 状态 | **待审批**（2026-04-22） |
| 所属 Feature | `.ai/features/feature-telemetry-ingest-governance.md` |
| 优先级 | P0 |
| 预估 | 1–2 天 |

---

## 1. 目标

定义并固化事件字典 v1，使后续 ingest 与报表口径稳定：

- 事件名列表（v1 核心事件）
- 每个事件允许的 properties 白名单与类型
- 脱敏与禁止字段清单
- 版本策略（event schema version）

---

## 2. 范围

### In Scope

- 文档化事件字典 v1（存放于仓库，供前后端共识）
- 服务端校验所需的结构（如 JSON schema 或 TS type 约束的载体定义）

### Out of Scope

- 自动生成埋点 SDK（后续 story）

---

## 3. 验收标准

1. 事件字典包含 PRD 5.2 的核心事件，并明确每个事件 properties 的白名单与类型。
2. 明确禁止采集字段（手机号/邮箱/姓名等）与处理策略（丢弃并计数或拒绝）。
3. 明确维度标准化：`source`、`platform`、`clientVersion` 的取值约束与默认值。

---

## 4. 测试策略

- 以字典为输入的单元测试：非法事件名、非法字段、敏感字段被拒绝/丢弃的用例（实现时补）。

---

## 5. 依赖

- 无（先行产出，供后续实现引用）
