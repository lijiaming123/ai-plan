# Plan Soft Delete (Trash) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow users to clean up “我的计划” list by deleting plans safely (soft-delete with undo/restore), while keeping API analytics and UX consistent.

**Architecture:** Implement soft-delete at DB level with `deletedAt` on `Plan`; list endpoints exclude deleted records; add trash list + restore endpoints. Frontend exposes “删除” in a low-emphasis card menu, provides immediate undo, and a “最近删除” view for restore.

**Tech Stack:** Fastify + Prisma (apps/api), Vue 3 (apps/web-user), Vitest, Postgres migrations via Prisma.

```ts
export async function softDeletePlan(userId: string, planId: string) {
  const plan = await prisma.plan.findFirst({
    where: { id: planId, userId },
    select: { id: true, deletedAt: true },
  });
  if (!plan) throw new Error('404');

  await prisma.plan.update({
    where: { id: planId },
    data: { deletedAt: new Date() },
  });
  return { ok: true };
}

export async function restorePlan(userId: string, planId: string) {
  const plan = await prisma.plan.findFirst({
    where: { id: planId, userId },
    select: { id: true },
  });
  if (!plan) throw new Error('404');

  await prisma.plan.update({
    where: { id: planId },
    data: { deletedAt: null },
  });
  return { ok: true };
}

export async function listTrashPlans(userId: string) {
  return prisma.plan.findMany({
    where: { userId, deletedAt: { not: null } },
    orderBy: { deletedAt: 'desc' },
    select: { id: true, goal: true, deadline: true, requirement: true, type: true, deletedAt: true, createdAt: true },
  });
}
```
